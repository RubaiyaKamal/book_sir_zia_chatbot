# Hello World Gemini

A Python project that displays a colorful "Hello, World!" message and a personalized greeting using the rich library.

## Features

- Displays a colorful "Hello, World!" message.
- Prompts the user for their name.
- Displays a personalized greeting.
- Uses the rich library for beautiful terminal output.

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/hello-world-gemini.git
   ```
2. Navigate to the project directory:
   ```bash
   cd hello-world-gemini
   ```
3. Install the dependencies:
   ```bash
   uv add rich
   ```

## Usage

Run the `main.py` file:

```bash
python main.py
```
